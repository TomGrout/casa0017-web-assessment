# Rain To Spill  

An interactive site for visualising rainfall and storm overflows in London. Uses measured flow direction during a discharge, showing when rising tides push raw sewage backward into Stratford's canal basins instead of washing it out to sea

Built with JavaScript, HTML & CSS, using:
- mapbox
- leaflet
- other libraries
